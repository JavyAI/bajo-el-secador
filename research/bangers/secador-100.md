## Method

1. Build the culturally correct candidate pool (memory, radio, ritual under the hood).
2. Attach the strongest **official** YouTube id (artist / VEVO / label / Topic).
3. Sort that pool by view count as a resonance **signal**.
4. Hand-check: would this body say *wow* in 15 seconds **in this room**?
5. Flag high-view / wrong-temperature songs. Ban 2020s urbano. Old school = 1970s–early 2010s.

**Official vs live JSON:** several salon embeds are newer remasters or live cuts with far fewer views than the monument official. This table ranks the **best official found**. The live player id is noted when it differs.

**What “views” means here:** one official upload, not summed across every upload of the same song. A 174M fan-letra of *La Gata* does not beat Rocío’s Topic (60M) for the official column.
