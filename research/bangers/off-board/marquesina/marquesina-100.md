Views scraped or searched 2026-08-16 from official / VEVO / artist / label / Topic / JN Music pages. Fan mixes noted, not used as the rank ID when a cleaner official exists.

## Method

1. Build the culturally correct candidate pool (memory, radio, ritual on the lot).
2. Attach the strongest **official** YouTube id (artist / VEVO / label / Topic / Karen / JN).
3. Sort that pool by view count as a resonance **signal**.
4. Hand-check: would this body say *wow* in 15 seconds **in this room** — tíos, primos, the quinceañera, the tía who still dances?
5. Flag high-view / wrong-temperature songs. Ban salsa monuments (Pedro Navaja, Gran Varón), dominó-colmado salsa, and 2024 dembow.

**Official vs live JSON:** several marquesina embeds are older fan/label cuts with far fewer views than the monument official (worst: *Tu Sonrisa* live id 3.2M vs VEVO 280M). This table ranks the **best official found**. The live player id is noted when it differs.

**What “views” means here:** one official upload, not summed across every upload of the same song. YouTube Music *plays* (Fulanito *Guallando* 231M plays) are **not** watch-page views. Topic / compilation autoplay is marked when it inflates a classic.

**Old school lock:** mostly pre-2012. 2016–17 merengue (*Dale Vieja Dale*, Chiquito *La Llamada*) is HOY even at 70M+.
